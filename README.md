# ClaudeChat Desktop

Claude API を使って、claude.ai のデスクトップ版のようにチャットできる Windows アプリです。
同じ機能のアプリを **Electron 版** と **ネイティブ版 (C# / WPF)** の 2 種類で作り、作り方の違いでどこまで差が出るかを比べられるようにしています。

趣味で作ったもので、商用利用は想定していません。

リポジトリ: https://github.com/nyankouu857-jpg/claude-chat-desktop

## できること

2 つのアプリは見た目も機能もほぼ同じです。

| 機能 | 内容 |
|---|---|
| ストリーミング表示 | 返答が 1 文字ずつ流れるように表示されます。途中で「停止」ボタンで止められます |
| 思考プロセス | Claude が回答前に考えた内容の要約を、折りたたみで見られます |
| Markdown 表示 | 見出し、箇条書き、表、太字、リンクなどを整形して表示します |
| コードブロック | 言語ごとの色分けと、ワンクリックのコピーができます |
| 会話履歴 | 左のサイドバーに自動保存されます。クリックで過去の会話に戻れます |
| タイトル自動生成 | 最初のやり取りが終わると、Claude Haiku 5.5 が会話に短いタイトルを付けます |
| 画像の添付 | 「画像」ボタン、貼り付け、ドラッグ&ドロップで画像を送れます |
| Web 検索 | 「Web検索」にチェックを入れると、Claude が必要に応じてネットを検索します |
| モデル切り替え | Opus 5.5 / Fable 5.1 / Sonnet 5.5 / Haiku 5.5 から選べます |
| 思考の深さ | low / medium / high / xhigh / max から選べます |
| システムプロンプト | 設定画面で、すべての会話に共通する指示を書けます |
| トークン数の表示 | 画面右上に、その会話で使った入力 / 出力 / キャッシュのトークン数が出ます |
| ダークモード | Windows の設定に合わせて自動で切り替わります |

## 最短で動かす: ビルド済みの exe をダウンロードする

開発ツールを何も入れずに試す方法です。GitHub が `main` ブランチに変更が入るたびに、両方の exe を自動でビルドしています。

### 手順

1. ブラウザで GitHub にログインします。Artifacts のダウンロードは、GitHub にログインしていないとできません。
2. https://github.com/nyankouu857-jpg/claude-chat-desktop/actions を開きます。
3. 一覧の一番上にある、緑のチェックが付いた「build」の実行をクリックします。
4. ページ下部の **Artifacts** に 2 つのファイルがあるので、使いたい方をクリックしてダウンロードします。
   - `ClaudeChat-Electron` : Electron 版
   - `ClaudeChat-Native` : ネイティブ版
5. ダウンロードした zip を右クリックして「すべて展開」します。
6. 中の exe をダブルクリックで起動します。
   - Electron 版: `ClaudeChat-Electron 0.1.0.exe`
   - ネイティブ版: `ClaudeChat.Native.exe`

どちらもインストール不要で、exe 1 つで動きます。好きなフォルダに置いて使ってください。

### 補足

- Artifacts は 90 日で消えます。消えていたら、Actions 画面左の「build」を選び、右上の **Run workflow** ボタンを押すと作り直せます。10 分ほどで完了します。
- 初回起動時に「Windows によって PC が保護されました」と出ることがあります。電子署名をしていない exe なので表示されるもので、「詳細情報」を押してから「実行」を押せば起動します。
- 動作環境は Windows 10 / 11 の 64bit です。

## API キーを用意する

アプリは Anthropic の API を直接呼び出します。claude.ai の有料プランとは別に、API 用のアカウントとキーが必要です。

1. https://console.anthropic.com にアクセスしてアカウントを作ります。
2. 「Billing」でクレジットを購入します。API は使った分だけ課金される前払い方式です。最初は 5 ドル程度で十分試せます。
3. 「API Keys」で「Create Key」を押してキーを発行します。`sk-ant-` で始まる文字列です。
4. 発行したキーはその場でしか表示されないので、コピーしておきます。

キーは他人に見せないでください。漏れた場合は console.anthropic.com で無効化して作り直せます。

## 初回起動と使い方

### 初回起動

1. アプリを起動すると、API キーが未登録なので設定画面が自動で開きます。
2. 「APIキー」欄に用意したキーを貼り付けます。
3. 必要なら「システムプロンプト」に共通の指示を書きます。例: `回答は簡潔に、日本語で`
4. 「保存」を押します。

キーは Windows の暗号化機能 DPAPI で暗号化して保存されます。同じ Windows ユーザーでしか復号できません。

### 基本の使い方

- 画面下の入力欄にメッセージを書き、**Enter** で送信します。
- 改行したいときは **Shift + Enter** です。
- 日本語入力の変換確定の Enter では送信されません。
- 返答中は「送信」ボタンが「停止」に変わります。押すとその時点までの本文が残ります。
- 新しい会話は、左上の「+ 新しいチャット」から始めます。
- 過去の会話はサイドバーをクリックすると開きます。「×」で削除できます。
- 返答中に別の会話へ移っても、裏で返答は続きます。応答中の会話にはサイドバーにオレンジの点が付きます。

### 画像を送る

次のどれかで画像を添付し、そのまま送信します。

- 入力欄の下の「画像」ボタンからファイルを選ぶ
- スクリーンショットなどをコピーして、入力欄で Ctrl + V
- 画像ファイルを入力欄の枠にドラッグ&ドロップ

対応形式は PNG / JPEG / GIF / WebP で、1 枚 5MB までです。

### Web 検索

入力欄の下の「Web検索」にチェックを入れると有効になります。Claude が必要と判断したときだけ検索します。
検索した場合は「Web を検索: 検索語」と表示され、参照したページの一覧を折りたたみで見られます。
API へのリクエスト 1 回につき最大 5 回まで検索します。

### モデルと思考の深さ

入力欄の右下で選べます。選んだ内容は保存され、次回起動時も引き継がれます。

- 思考の深さは、上げるほど難しい問題に強くなる代わりに、時間と料金がかかります。
- 普段の会話なら `low` か `medium` で十分です。
- 設計の相談や難しいコードの相談では `high` 以上を試してください。

## 自分のパソコンでビルドする

ソースを改造したい場合や、自分でビルドしたい場合の手順です。

### 共通: ソースを取得する

Git を使う場合:

```
git clone https://github.com/nyankouu857-jpg/claude-chat-desktop.git
cd claude-chat-desktop
```

Git を使わない場合は、リポジトリのページの緑の「Code」ボタンから「Download ZIP」でダウンロードして展開します。

### Electron 版

必要なもの: Node.js 22 以上。https://nodejs.org から LTS 版をインストールします。

```
cd electron
npm install
```

開発用に起動する場合:

```
npm start
```

exe を作る場合:

```
npm run dist
```

`electron/release/ClaudeChat-Electron 0.1.0.exe` ができます。

その他のコマンド:

| コマンド | 内容 |
|---|---|
| `npm run build` | `src` を `dist` にまとめるだけで、起動はしません |
| `npm run typecheck` | TypeScript の型チェック |

開発用に起動したとき、F12 で開発者ツールが開きます。

### ネイティブ版

必要なもの: .NET 10 SDK。https://dotnet.microsoft.com/download から「.NET 10.0」の SDK をインストールします。

```
cd native
dotnet run
```

exe を作る場合:

```
dotnet publish -c Release -o publish
```

`native/publish/ClaudeChat.Native.exe` ができます。.NET ランタイムを同梱した exe なので、配布先に .NET が入っていなくても動きます。

.NET 10 に対応した最新の Visual Studio があれば、`native/ClaudeChat.Native.csproj` を開いて F5 で実行することもできます。

### 環境変数で API キーを渡す

設定画面でキーを登録していない場合、環境変数 `ANTHROPIC_API_KEY` の値を使います。開発中に毎回キーを入れたくないときに便利です。

```
set ANTHROPIC_API_KEY=sk-ant-...
npm start
```

## モデルと料金の目安

料金は 100 万トークンあたりの米ドルです。2026 年 10 月時点の公式価格で、変わることがあります。最新の価格は https://www.anthropic.com/pricing で確認してください。

| 選択肢 | モデル ID | 入力 | 出力 | 特徴 |
|---|---|---|---|---|
| Opus 5.5 | `claude-opus-5-5` | $4 | $20 | 標準。賢さと料金のバランスが良い |
| Fable 5.1 | `claude-fable-5-1` | $10 | $50 | 最も賢いが高い |
| Sonnet 5.5 | `claude-sonnet-5-5` | $2 | $10 | 速くて安い。普段使い向け |
| Haiku 5.5 | `claude-haiku-5-5` | $0.10 | $0.50 | とても安い。簡単な質問向け |

日本語はおおよそ 1 文字 1 トークン前後です。

- API は会話のたびに、それまでの履歴を全部送り直します。会話が長くなるほど 1 回あたりの入力トークンが増えます。
- このアプリはプロンプトキャッシュを有効にしています。同じ会話を続ける限り、前回までの履歴は割安なキャッシュ料金で読まれます。
- 長い話題が終わったら「新しいチャット」で始め直すと節約になります。
- 思考の深さを上げると、思考の分の出力トークンが増えます。
- Web 検索には、トークン料金とは別に検索回数ごとの料金がかかります。

実際の使用額は console.anthropic.com の「Usage」で確認できます。

## データの保存場所と削除方法

会話履歴と設定は、パソコンの中にだけ保存されます。どこかのサーバーに保存されることはありません。
ただし、送ったメッセージと画像は回答を作るために Anthropic の API に送信されます。

| アプリ | 保存場所 |
|---|---|
| Electron 版 | `%APPDATA%\ClaudeChat-Electron` |
| ネイティブ版 | `%APPDATA%\ClaudeChat.Native` |

エクスプローラーのアドレス欄に上の場所をそのまま入力すると開けます。

| ファイル | 中身 |
|---|---|
| `settings.json` | モデル、思考の深さ、システムプロンプト、暗号化した API キー |
| `conversations\index.json` | サイドバーに出す会話の一覧 |
| `conversations\<ID>.json` | 会話 1 件分の履歴。API に送るのと同じ形式の JSON です |

- すべてのデータを消したいときは、アプリを閉じてからこのフォルダごと削除します。
- API キーだけ消したいときは、`settings.json` を削除します。他の設定も初期値に戻ります。
- 2 つのアプリの履歴は別々に保存されていて、共有はされません。

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「APIキーが無効です」と出る | キーの貼り間違いか、無効化されたキーです。設定画面から入れ直してください |
| 「このモデルを使う権限がありません」と出る | アカウントでそのモデルが使えません。別のモデルを選んでください |
| 「レート制限に達しました」と出る | 短時間に送りすぎです。少し待ってから送り直してください |
| 「リクエストが拒否されました」と出て、残高不足の内容が書かれている | console.anthropic.com でクレジットを追加してください |
| 「API に接続できません」と出る | ネットワークを確認してください。社内ネットワークではプロキシで止められていることがあります |
| 「Claude がこのリクエストへの応答を断りました」と出る | 安全上の理由で回答が止められました。言い回しを変えるか、別のモデルで試してください |
| 「出力上限に達したため途中で終わっています」と出る | 回答が長すぎました。「続きをお願いします」と送ると続きが返ってきます |
| 起動時に「Windows によって PC が保護されました」と出る | 「詳細情報」を押してから「実行」を押してください |
| Electron 版の起動に数秒かかる | 起動のたびに一時フォルダへ展開する形式のためです。仕様です |
| 画面が真っ白のまま動かない | Electron 版なら F12 で開発者ツールを開き、Console タブのエラーを確認してください |

### Claude が回答を断ったときの自動再試行

Opus 5.5、Fable 5.1、Sonnet 5.5 では、Claude が安全上の理由で回答を断った場合に、Anthropic 側が自動で別のモデルに切り替えて回答を続ける設定を入れています。
切り替わったときは、返答の中に「〇〇 が応答を断ったため 〇〇 が続きを書きました」と表示されます。
Haiku 5.5 はこの仕組みに対応していないため、断られた場合はそのまま止まります。

## Electron 版とネイティブ版の比較

### 作り方の違い

| | Electron 版 | ネイティブ版 |
|---|---|---|
| 言語 | TypeScript | C# |
| 画面 | HTML と CSS。中身は Chromium | WPF。Windows の描画機能を直接使う |
| Claude API の呼び出し | 公式 TypeScript SDK | 公式 C# SDK |
| Markdown 表示 | marked と DOMPurify | Markdig で解析し、WPF の文書形式に自前で変換 |
| コードの色分け | highlight.js。約 190 言語の文法に対応 | 自前の簡易版。キーワード、文字列、コメント、数値だけ |
| API キーの暗号化 | Electron の safeStorage | Windows の DPAPI |
| 標準コントロールの見た目 | 自分で CSS を書く | Windows 11 の Fluent デザインが自動で適用される |

### 実測した数字

| 項目 | Electron 版 | ネイティブ版 |
|---|---|---|
| 配布する exe 1 つのサイズ | 99MB | 68MB |
| 実行時に展開される容量 | 369MB | 展開なし |
| そのうちアプリ自身のコード | 1.4MB | 下の 10MB に SDK などと一緒に含まれる |
| .NET を別途入れる前提にした場合の exe | 作れない | 10MB |
| ソースコードの行数 | 約 1400 行 | 約 1800 行 |

### 作ってみて分かったこと

- **見た目を作る手間は Electron の方が圧倒的に少ないです。** Markdown やコードの色分けは既存のライブラリでほぼ終わり、CSS で claude.ai 風の見た目に簡単に寄せられます。
- **ネイティブ版は表示部分を自分で書く量が多くなります。** Markdown を WPF の文書に組み替える処理と、コードの色分けを自前で書いたため、行数が増えています。色分けの精度も Electron 版に劣ります。
- **ネイティブ版はサイズが小さく、起動時の展開がありません。** Electron 版の portable 形式は起動のたびに 369MB 分を一時フォルダへ展開します。
- **ネイティブ版は Windows らしい操作感になります。** コンボボックスやチェックボックスは Windows 11 標準の見た目です。日本語入力の変換確定で誤送信しない処理も、WPF では素直に書けました。
- **Electron 版はそのまま Mac や Linux 向けにも作れます。** WPF は Windows 専用です。

### 自分で比べてみると面白いところ

両方を起動して、次の点を見比べてみてください。数字はこのリポジトリではまだ測れていません。

- 起動してから画面が出るまでの時間
- タスクマネージャーで見たメモリ使用量。Electron 版は複数のプロセスに分かれているので、合計で比べます
- 長い会話をスクロールしたときの滑らかさ
- 長いコードが流れてくるときの描画の軽さ
- テキストを選択してコピーするときの操作感

### 1 回のやり取りの流れ

両方のアプリで同じ流れです。

1. 入力欄のメッセージを、会話履歴の末尾に追加して保存します。
2. 会話履歴全体と設定を Claude API に送ります。ストリーミング形式で受け取ります。
3. 届いた断片を、思考、本文、検索などの表示用の部品に振り分けて、少しずつ画面に描きます。
4. 返答が終わったら、API から返ってきた内容を加工せずに履歴へ追加して保存します。
5. 最初のやり取りなら、Haiku 5.5 に会話のタイトルを付けてもらいます。

### 履歴を加工せずに保存している理由

Claude の思考ブロックには、改ざん検知用の署名が付いています。次の送信で同じモデルに返すときは、1 文字も変えずに返す必要があります。
Web 検索の結果にも暗号化された中身が含まれます。
そのため、履歴は API とやり取りする JSON の形のまま保存しています。

## 既知の制限

- 実際の Windows ではまだ動作確認をしていません。開発環境の Linux 上で、Electron 版は実機と同じ Chromium で、ネイティブ版は Wine という Windows 互換環境で動作を確認しました。確認には Anthropic API の代わりに、同じ形式で返答するテスト用サーバーを使いました。
- 会話を途中から編集したり、返答を再生成したりする機能はありません。
- PDF などの画像以外のファイルは添付できません。
- 会話の検索機能はありません。
- 停止ボタンで止めた返答は、それまでの本文だけが残り、思考プロセスは残りません。
- ネイティブ版のコードの色分けは簡易版なので、言語によっては色が付かない部分があります。
- 2 つのアプリの間で会話履歴は共有されません。
