# ClaudeChat Desktop

Claude API を使って、claude.ai のデスクトップ版のようにチャットできる Windows アプリです。趣味で作ったもので、商用利用は想定していません。

このリポジトリには 3 つの版が入っています。**ふだん使うのは ClaudeChat** です。

| 版 | フォルダ | 中身 | 位置づけ |
|---|---|---|---|
| **ClaudeChat** | `hybrid/` | 画面は Web 技術、中身は C# のネイティブ | 本命。claude.ai に寄せた画面、コネクタ (MCP)、料金表示つき |
| Electron 版 | `electron/` | すべて TypeScript と Electron | 比較用の最初の版 |
| ネイティブ版 | `native/` | すべて C# と WPF | 比較用の最初の版 |

リポジトリ: https://github.com/nyankouu857-jpg/claude-chat-desktop

## ダウンロードして使う

### 手順

1. https://github.com/nyankouu857-jpg/claude-chat-desktop/releases/latest を開きます。
2. Assets にある **`ClaudeChat.zip`** をダウンロードします。
3. zip を右クリックして「すべて展開」します。中に `ClaudeChat` フォルダができます。
4. `ClaudeChat` フォルダを、好きな場所に置きます。ドキュメントやデスクトップなど、自分のユーザーで書き込める場所がおすすめです。
5. フォルダの中の `ClaudeChat.exe` をダブルクリックして起動します。

インストールは不要です。設定や会話履歴は、すべてこの `ClaudeChat` フォルダの中に保存されます。フォルダごとコピーすればバックアップや別の場所への移動ができます。

### 補足

- **動作環境:** Windows 10 / 11 の 64bit です。
- **WebView2:** 画面の表示に Microsoft Edge WebView2 ランタイムを使います。Windows 10 / 11 には最初から入っています。入っていない場合は起動時に案内が出るので、そこからダウンロードしてください。
- **警告が出たとき:** 初回起動時に「Windows によって PC が保護されました」と出ることがあります。電子署名をしていない exe なので表示されるもので、「詳細情報」を押してから「実行」を押せば起動します。
- **Releases が見えないとき:** リポジトリが private の場合は、GitHub にログインした状態で開いてください。
- **最新版への更新:** `main` に変更が入るたびに、Releases の `latest` が自動で作り直されます。更新するときは、新しい zip の `ClaudeChat.exe` だけを古いものに上書きしてください。`config` や `data` のフォルダはそのまま使えます。
- **比較用の 2 つの版:** 同じ Releases に `ClaudeChat-Electron.zip` と `ClaudeChat-Native.zip` もあります。

## API キーを用意する

このアプリは Anthropic の API を直接呼び出します。claude.ai の有料プランとは別に、API 用のアカウントとキーが必要です。

1. https://console.anthropic.com にアクセスしてアカウントを作ります。
2. 「Billing」でクレジットを購入します。API は使った分だけ引かれる前払い方式です。最初は 5 ドル程度で十分試せます。
3. 「API Keys」で「Create Key」を押してキーを発行します。`sk-ant-` で始まる文字列です。
4. キーはその場でしか表示されないので、コピーしておきます。

初回起動時は設定の「API とモデル」画面が自動で開きます。そこにキーを貼って「保存」を押し、「接続テスト」で確認してください。

キーは Windows の DPAPI で暗号化して `config/secrets.json` に保存されます。同じ PC の同じ Windows ユーザーでしか復号できません。

## 画面の使い方

画面は claude.ai とほぼ同じ構成です。

### サイドバー

| 項目 | できること |
|---|---|
| Claude の横のボタン | サイドバーを細くたたみます。もう一度押すと戻ります |
| 新しいチャット | 新しい会話を始めます |
| チャット | すべての会話の一覧です。タイトルと最初の発言で検索できます |
| コネクタ | MCP サーバーの登録画面を開きます |
| 使用量 | 料金と使用量の画面を開きます |
| スター付き | スターを付けた会話が上にまとまります |
| 最近の項目 | 会話の履歴です。右端の「…」からスター、名前の変更、削除ができます |
| 左下の名前 | 設定、使用量、アプリのフォルダを開くメニューです |

応答中の会話には、サイドバーにオレンジの点が付きます。返答の途中で別の会話に移っても、裏で返答は続きます。

### 入力欄

- **送信と改行:** Enter で送信、Shift + Enter で改行です。日本語入力の変換確定の Enter では送信されません。
- **＋ ボタン:** 画像を添付します。貼り付けやドラッグ&ドロップでも添付できます。対応形式は PNG / JPEG / GIF / WebP で、1 枚 5MB までです。
- **つまみのボタン:** Web 検索と、各コネクタのオンオフを切り替えます。数字はオンになっている数です。
- **モデル名のボタン:** モデルと思考の深さを選びます。ここで選んだ内容は、アプリを閉じるまで有効です。
- **送信ボタン:** 返答中は停止ボタンに変わります。止めると、それまでに出た本文だけが残ります。

### 会話の表示

| 表示 | 内容 |
|---|---|
| 思考プロセス | Claude が答える前に考えた内容の要約です。クリックで開きます。考えている間は経過秒数が出ます |
| Web を検索しました | 検索した言葉と、参照したページの一覧です |
| ツールのカード | コネクタのツールを使った記録です。開くと入力と結果が見られます |
| オレンジのマーク | 最新の回答の下に出ます。返答中は回転します |

回答の下にマウスを置くと、コピーとやり直しのボタンが出ます。自分の発言にマウスを置くと、コピーと編集のボタンが出ます。編集して送ると、その発言から後の会話を作り直します。

### ツールを使う前の確認

Claude がコネクタのツールやフォルダへの書き込みを使おうとすると、実行前に確認のカードが出ます。

- **常に許可:** 同じツールは次から確認なしで実行します。設定の「ツールの権限」で取り消せます。
- **今回だけ許可:** 今回だけ実行します。
- **拒否:** 実行せず、Claude に許可されなかったことを伝えます。

### 設定画面

| タブ | できること |
|---|---|
| 一般 | 氏名、呼び名、個人設定。個人設定はすべての会話の指示に入ります |
| 外観 | ライト、ダーク、自動の切り替えと、回答のフォント |
| API とモデル | API キーの登録と接続テスト、既定のモデル、思考の深さ、Web 検索、ツール呼び出しの上限回数 |
| フォルダ | Claude に読み書きさせるフォルダの登録。次の「フォルダを操作する」を参照 |
| コネクタ | MCP サーバーの追加、編集、削除、有効と無効の切り替え、再起動、ログの確認 |
| ツールの権限 | 常に許可しているツールの一覧と取り消し |
| 使用量と料金 | アプリでの利用額と、Anthropic の請求データ |
| データ | 代表フォルダの場所、設定ファイルを開く、再読み込み |

## 代表フォルダの中身

`ClaudeChat.exe` を置いたフォルダが代表フォルダです。初回起動時に、次のフォルダが自動で作られます。

```
ClaudeChat/
├── ClaudeChat.exe
├── config/
│   ├── settings.json        アプリの設定とコネクタの登録
│   ├── secrets.json         暗号化した API キー
│   └── pricing.json         料金の計算に使う単価表
├── data/
│   ├── conversations/       会話履歴 (index.json と会話ごとの JSON)
│   └── usage/               使用量の記録 (月ごとの .jsonl) と請求データのキャッシュ
├── logs/                    コネクタごとのログ (mcp-名前.log)
└── cache/                   画面表示部品のキャッシュ
```

- **バックアップ:** アプリを閉じてから `ClaudeChat` フォルダごとコピーします。
- **別の PC へ移す:** フォルダごと移せば設定と履歴はそのまま使えます。API キーだけは暗号化の都合で入れ直しが必要です。
- **すべて消す:** フォルダごと削除します。代表フォルダの外には何も残りません。
- **書き込めない場所に置いたとき:** `C:\Program Files` のように書き込めない場所に exe を置いた場合だけ、代わりに `%LOCALAPPDATA%\ClaudeChat` を使います。そのときは設定の「データ」に注意が表示されます。exe を書き込める場所に移せば、代表フォルダに戻ります。
- **二重起動:** 同じ代表フォルダの exe は 1 つしか起動できません。履歴が壊れるのを防ぐためです。

## 設定ファイルを直接編集する

設定の多くは画面から変更できますが、`config/settings.json` を直接編集することもできます。編集したら、設定の「データ」で「再読み込み」を押してください。

```json
{
  "profile": {
    "fullName": "山田 太郎",
    "nickname": "たろう",
    "preferences": "回答は簡潔に、結論から書いてください。"
  },
  "appearance": {
    "theme": "system",
    "chatFont": "default"
  },
  "chat": {
    "model": "claude-opus-5-5",
    "effort": "medium",
    "webSearch": false,
    "showThinking": true,
    "maxToolTurns": 30
  },
  "files": {
    "enabled": true,
    "autoApproveReads": true,
    "folders": [
      { "path": "C:\\Users\\taro\\Documents\\memo", "readOnly": false },
      { "path": "D:\\資料", "readOnly": true }
    ]
  },
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\taro\\Documents"]
    }
  },
  "toolPermissions": {
    "filesystem__read_file": "always"
  }
}
```

| 項目 | 内容 |
|---|---|
| `profile.preferences` | すべての会話の指示に入る個人設定 |
| `appearance.theme` | `light` / `dark` / `system` |
| `appearance.chatFont` | `default` は明朝体、`sans` はゴシック体、`large` は大きめ |
| `chat.model` | 既定のモデル ID。下の「モデルと料金の目安」を参照 |
| `chat.effort` | `low` / `medium` / `high` / `xhigh` / `max` |
| `chat.maxToolTurns` | 1 回の返答で続けてツールを呼べる上限 |
| `files.enabled` | フォルダ操作を使うかどうか |
| `files.autoApproveReads` | 読み取りだけのツールを確認なしで実行するかどうか |
| `files.folders` | 許可するフォルダ。`readOnly` を `true` にすると書き込めません。先頭が相対パスの基準です |
| `mcpServers` | コネクタの登録。「コネクタ (MCP) を登録する」を参照 |
| `toolPermissions` | 確認なしで実行するツール |

いちばん外側に知らない項目を書き足しても、アプリが保存し直したときに消されずに残ります。

`config/pricing.json` は料金の計算に使う単価表です。価格改定があったら書き換えて、設定の「使用量と料金」で「料金表を再読み込み」を押してください。

`config/secrets.json` は暗号化されているので、直接は編集できません。キーは画面から登録してください。

## フォルダを操作する

許可したフォルダの中だけ、Claude がファイルを読んだり書いたりできます。コネクタを入れなくても、アプリに組み込みで入っています。

### 使い始める

1. 設定の「フォルダ」を開き、「フォルダ操作を使う」をオンにします。
2. 「参照」でフォルダを選ぶか、パスを貼り付けて「追加」を押します。
3. 書き換えてほしくないフォルダは「読み取り専用」をオンにします。
4. 会話で「メモフォルダの中身を一覧にして」「todo.md に今日のタスクを書いて」のように頼みます。

入力欄のつまみのボタンにある「フォルダ」で、会話ごとにオフにできます。

### できること

| 操作 | 内容 | 確認 |
|---|---|---|
| フォルダの中身を見る | ファイルとフォルダの一覧。最大 500 件 | なし |
| ファイルを読む | 行番号つきで読みます。長いファイルは 2000 行ずつ。画像は画像として Claude に見せます | なし |
| ファイルを探す | 名前のパターンや中身の文字で探します。最大 200 件 | なし |
| ファイルの情報を見る | サイズ、更新日時など | なし |
| ファイルに書き込む | 新しく作るか、まるごと書き換えます | あり |
| ファイルを編集する | 一部の文字を置き換えます | あり |
| フォルダを作る、移動する、コピーする | 名前の変更も移動に含みます | あり |
| 削除する | ごみ箱に移します。完全には消しません | あり |

「確認」が「なし」の操作は、設定の「読み取りは確認なしで実行する」をオフにすると、毎回確認が出るようになります。

### 安全のための仕組み

- **許可フォルダの外には出られません:** `..` やショートカット、ジャンクション、シンボリックリンクを使って外へ出ようとしても拒否します。
- **読み取り専用のフォルダには書き込めません。**
- **登録したフォルダそのものは移動も削除もできません。** 中身だけを操作できます。
- **削除はごみ箱へ:** 間違えて消されても、ごみ箱から戻せます。
- **文字コードを保ちます:** Shift_JIS や BOM つきのファイルは、書き換えても元の文字コードのままです。改行が CRLF のファイルも CRLF のままです。新しいファイルは BOM なしの UTF-8 で作ります。
- **探さない場所:** `node_modules`、`.git`、`bin`、`obj` と、隠しファイルやシステムファイルは検索の対象外です。
- **大きいファイル:** 20MB を超えるテキストと 5MB を超える画像は読みません。中身の検索では 2MB を超えるファイルを飛ばします。

### Claude に伝えている内容

フォルダ操作がオンの会話では、許可しているフォルダの一覧と、読み取り専用かどうかを Claude への指示に入れています。Claude はこれを見て、どこを操作できるかを判断します。指示に入る内容は「仕組み」の章を参照してください。

## コネクタ (MCP) を登録する

コネクタは MCP (Model Context Protocol) サーバーのことです。つなぐと、Claude がファイルの読み書きや外部サービスの操作などのツールを使えるようになります。

### 画面から登録する

1. サイドバーの「コネクタ」を開きます。
2. 「カスタムコネクタを追加」を押します。
3. 種類を選んで入力し、保存します。
   - **ローカル:** PC 上でコマンドを起動するタイプです。コマンド、引数 (1 行に 1 つ)、環境変数 (`KEY=VALUE`)、作業フォルダを指定します。
   - **リモート:** URL で接続するタイプです。URL と、必要ならヘッダー (`Authorization: Bearer xxx` など) を指定します。
4. カードの点が緑の「接続中」になれば使えます。「ツール N 個」を押すと、使えるツールが見られます。

### JSON で登録する

「JSON で編集」を押すと、Claude Desktop の `claude_desktop_config.json` と同じ書き方で編集できます。MCP サーバーの説明書にある設定を、そのまま貼り付けられます。`{"mcpServers": {...}}` の形でも、中身だけでも受け付けます。

例: ドキュメントフォルダを読み書きできるようにする

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\Users\\taro\\Documents"]
    }
  }
}
```

例: リモートの MCP サーバーにつなぐ

```json
{
  "mcpServers": {
    "my-remote": {
      "type": "http",
      "url": "https://example.com/mcp",
      "headers": { "Authorization": "Bearer xxxxx" }
    }
  }
}
```

例: GitHub につなぐ

GitHub 公式の MCP サーバーに、個人用アクセストークンで接続します。トークンは GitHub の Settings → Developer settings → Personal access tokens で作ります。`X-MCP-Toolsets` で使う機能を絞ると、毎回のリクエストに載るツールの説明が減って入力トークンを節約できます。書き込みをさせたくないときは `"X-MCP-Readonly": "true"` を足します。

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer github_pat_xxxx",
        "X-MCP-Toolsets": "repos,issues,pull_requests"
      }
    }
  }
}
```

「unauthorized: token authentication failed」と出るときは、ヘッダーは届いていて、GitHub がトークンを無効と判断しています。PowerShell で次を実行し、トークン自体が使えるか確かめてください。401 が返るなら、トークンを作り直す必要があります。

```
curl.exe -H "Authorization: Bearer github_pat_xxxx" https://api.github.com/user
```

PC 上で動かしたい場合は、Docker Desktop を入れて次のように登録します。

```json
{
  "mcpServers": {
    "github": {
      "command": "docker",
      "args": ["run", "-i", "--rm", "-e", "GITHUB_PERSONAL_ACCESS_TOKEN", "-e", "GITHUB_TOOLSETS", "ghcr.io/github/github-mcp-server"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "github_pat_xxxx",
        "GITHUB_TOOLSETS": "repos,issues,pull_requests"
      }
    }
  }
}
```

### 注意

- **トークンは平文で保存されます:** ヘッダーや環境変数に書いたトークンは、`config/settings.json` にそのまま保存されます。権限を絞ったトークンを使い、代表フォルダを人に渡すときは消してください。
- **Node.js が必要なもの:** `npx` で起動するサーバーには Node.js が必要です。https://nodejs.org から入れてください。Python 製のサーバーなら `uvx` などが必要です。
- **`.cmd` のコマンド:** `npx` のような `.cmd` 形式のコマンドは、アプリが自動で `cmd.exe /c` を付けて起動します。
- **初回の起動:** `npx` の初回ダウンロードや Docker の起動で、接続まで時間がかかることがあります。最大 2 分待ちます。
- **エラーのとき:** カードのエラー表示と、ファイルのアイコンから開けるログを確認してください。
- **会話ごとのオンオフ:** 入力欄のつまみのボタンで、コネクタを会話ごとにオフにできます。
- **OAuth:** OAuth でログインが必要なリモートサーバーには、まだ対応していません。ヘッダーでトークンを渡せるものは使えます。

## 使用量と料金を確認する

設定の「使用量と料金」には 2 種類の数字が出ます。

### このアプリでの利用

アプリから送ったリクエストごとに、トークン数を `data/usage/` に記録しています。料金は `config/pricing.json` の単価から計算した目安です。

- 今月、先月、累計の金額と回数
- 今月の日別のグラフ
- モデル別の内訳 (今月と累計を切り替え可能)
- 月別の一覧

会話ごとの金額は、チャット画面の右上にも出ます。

### Anthropic の請求データ

Console の Cost 画面と同じデータを取得します。アプリを使う前の利用分や、他のツールからの利用分も含まれます。

1. 期間を選びます。今月、先月、過去 30 日、全期間から選べます。
2. 「取得する」を押します。

このデータは Anthropic の Admin API から取得します。

- **通常の API キー:** まずは通常の API キーで試します。キーの種類によっては取得できます。
- **Admin API キー:** 取得できない場合は、Console の「Settings → Admin Keys」で作った Admin API キー (`sk-ant-admin` で始まるもの) を登録してください。
- **個人アカウント:** Admin API は個人アカウントでは使えません。Console の「Settings → Organization」で組織を作成すると使えるようになります。
- **反映の遅れ:** 利用してから数分で反映されます。
- **全期間の取得:** 全期間は初回だけ時間がかかります。取得済みの日は `data/usage/anthropic-cost-cache.json` に保存し、2 回目からは直近の数日分だけ取り直します。

## モデルと料金の目安

料金は 100 万トークンあたりの米ドルです。2026 年 10 月時点の公式価格で、変わることがあります。

| 選択肢 | モデル ID | 入力 | 出力 | 特徴 |
|---|---|---|---|---|
| Opus 5.5 | `claude-opus-5-5` | $4 | $20 | 標準。賢さと料金のバランスが良い |
| Fable 5.1 | `claude-fable-5-1` | $10 | $50 | 最も賢いが高い |
| Sonnet 5.5 | `claude-sonnet-5-5` | $2 | $10 | 速くて安い。普段使い向け |
| Haiku 5.5 | `claude-haiku-5-5` | $0.10 | $0.50 | とても安い。簡単な質問向け |

- **日本語のトークン数:** 日本語はおおよそ 1 文字 1 トークン前後です。
- **会話が長いと高くなる:** API は会話のたびにそれまでの履歴を全部送り直すので、会話が長くなるほど 1 回あたりの入力が増えます。
- **プロンプトキャッシュ:** 有効にしてあるので、同じ会話を続ける限り、前回までの履歴は割安な料金で読まれます。
- **思考の深さ:** 上げるほど、思考の分の出力トークンが増えます。
- **Web 検索:** トークン料金とは別に、検索 1000 回あたり 10 ドルかかります。
- **会話のタイトル:** 最初のやり取りのあとに Haiku 5.5 でタイトルを付けています。1 回あたり 0.01 ドル未満です。
- **回答を断られたとき:** Opus 5.5、Fable 5.1、Sonnet 5.5 では、Claude が安全上の理由で回答を断った場合に、Anthropic 側で別のモデルに切り替えて続ける設定を入れています。切り替わると、回答の中にその旨が表示されます。

## 仕組み

### 全体の構成

```
ClaudeChat.exe
├── WPF のウィンドウ (hybrid/App)
│   └── WebView2 で画面を表示。画面のファイルは exe に埋め込み
├── 画面 (hybrid/web)      React と TypeScript。claude.ai 風の見た目
└── 中身 (hybrid/Core)     C#。API 呼び出し、ツール、保存、料金計算
```

画面と中身は JSON のメッセージでやり取りします。

- **画面から中身へ:** `{ id, method, params }` の形で要求を送ります。例は `chat.send` や `settings.update` です。
- **中身から画面へ:** 要求への返事は `{ id, result }` です。ストリーミングの途中経過などの通知は `{ event, data }` で送ります。

通信路は WebView2 の `postMessage` です。開発用ホストでは、同じメッセージを WebSocket で送ります。中身のコードは同じものを使っています。

### 1 回の返答の流れ

1. 発言を会話履歴に追加して保存します。
2. 履歴、個人設定、Web 検索、コネクタのツール一覧を付けて、ストリーミングで API に送ります。
3. 届いた断片を、思考、本文、検索、ツール呼び出しに振り分けて画面へ送ります。
4. Claude がツールを使うと言ったら、確認を出し、許可されたら MCP サーバーか組み込みのフォルダ操作で実行します。その結果を返して、2 に戻ります。
5. 返答が終わったら保存し、使用量を記録します。最初のやり取りなら会話にタイトルを付けます。

### Claude への指示 (システムプロンプト)

API は、送る側が指示を付けない限り、何の指示もない状態で答えます。claude.ai が使っている指示は API には付きません。

このアプリは、次の短い指示を毎回付けています。

1. 今日の日付と曜日
2. 設定の「一般」の呼び名。空なら氏名
3. フォルダ操作がオンの会話だけ、許可しているフォルダの一覧
4. 設定の「一般」の個人設定

どれも空なら日付だけになります。

### 履歴を API の形のまま保存している理由

- **思考ブロック:** Claude の思考ブロックには改ざん検知用の署名が付いています。次の送信で同じモデルに返すときは、1 文字も変えずに返す必要があります。
- **Web 検索の結果:** 暗号化された中身が含まれます。

そのため会話履歴は、API とやり取りする JSON の形のまま `data/conversations/` に保存しています。

### これからの拡張に向けて

ツールは `IToolProvider` という共通の口で扱っています。MCP サーバーと組み込みのフォルダ操作は、どちらもこの口を通っています。同じ口で、ほかの組み込みのツールも足せます。たとえば次のようなものです。

- ターミナルでのコマンド実行
- ブラウザの操作
- exe の起動

ツールを実行する前の確認の仕組みも、すべてのツールで共通です。

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「APIキーが無効です」と出る | キーの貼り間違いか、無効化されたキーです。設定の「API とモデル」で入れ直してください |
| 「このモデルを使う権限がありません」と出る | アカウントでそのモデルが使えません。別のモデルを選んでください |
| 「レート制限に達しました」と出る | 短時間に送りすぎです。少し待ってから「再試行」を押してください |
| 残高不足の内容が書かれたエラーが出る | console.anthropic.com でクレジットを追加してください |
| 「API に接続できません」と出る | ネットワークを確認してください。社内ネットワークではプロキシで止められていることがあります |
| 「Claude がこのリクエストへの応答を断りました」と出る | 安全上の理由で回答が止められました。言い回しを変えるか、別のモデルで試してください |
| 「出力上限に達したため途中で終わっています」と出る | 回答が長すぎました。「続きをお願いします」と送ってください |
| 「ツールの呼び出しが N 回に達したので止めました」と出る | 設定の「API とモデル」で上限を上げるか、「続けて」と送ってください |
| コネクタが「エラー」になる | カードのエラー表示とログを確認してください。`npx` なら Node.js が入っているか確認してください |
| 起動時に WebView2 が無いと出る | 案内に従って WebView2 ランタイムを入れてください |
| 「すでに起動しています」と出る | 同じフォルダの ClaudeChat がタスクバーやタスクマネージャーに残っていないか確認してください |
| 画面がおかしい | 画面を右クリックして「検査」を選ぶと開発者ツールが開きます。Console タブのエラーを確認してください |
| 「Windows によって PC が保護されました」と出る | 「詳細情報」を押してから「実行」を押してください |

## 3 つの版の比較

最初に Electron 版とネイティブ版を作って比べ、その結果から ClaudeChat の構成を決めました。

### 作り方の違い

| | Electron 版 | ネイティブ版 | ClaudeChat |
|---|---|---|---|
| 画面 | HTML と CSS。中身は同梱の Chromium | WPF。Windows の描画機能を直接使う | HTML と CSS。表示は Windows 内蔵の WebView2 |
| 中身 | TypeScript | C# | C# |
| Claude API | 公式 TypeScript SDK | 公式 C# SDK | 公式 C# SDK |
| Markdown | marked、highlight.js | Markdig を WPF の文書に自前で変換 | marked、highlight.js、KaTeX |
| コネクタ (MCP) | なし | なし | 公式 C# MCP SDK |
| 料金表示 | トークン数のみ | トークン数のみ | 金額、日別グラフ、請求データ |

### 実測した数字

| 項目 | Electron 版 | ネイティブ版 | ClaudeChat |
|---|---|---|---|
| 配布する exe | 99MB | 68MB | 70MB |
| 実行時に展開される容量 | 369MB | 展開なし | 展開なし |

### 分かったこと

- **見た目:** 実際に使ってみると、見た目の豊かさは Electron 版がはっきり上でした。
- **中身:** ネイティブ版は軽く、Windows の機能を直接使いやすい利点がありました。
- **ClaudeChat の構成:** 両方の良いところを取るため、画面は Web 技術、中身は C# にしました。画面の表示には Windows に最初から入っている WebView2 を使うので、Chromium を同梱する Electron よりも小さくなります。

## 既知の制限

- **実機での確認:** ClaudeChat のウィンドウ部分は、まだ Windows 実機で動作確認をしていません。画面と中身は、開発用ホストとブラウザで動作を確認しています。確認には、Anthropic API と同じ形式で返答するテスト用サーバーと、テスト用の MCP サーバーを使いました。ウィンドウ部分は Linux 上でビルドが通ることまで確認しています。
- **Claude.ai との違い:** claude.ai の実際の画面はログインが必要なため、直接見比べてはいません。細かい見た目が違う部分があります。
- **未対応の機能:** プロジェクト、アーティファクト、会話の共有、発言の分岐の切り替えはありません。
- **添付:** PDF など画像以外のファイルは添付できません。
- **停止した返答:** 停止すると、それまでの本文だけが残り、思考プロセスは残りません。
- **履歴の共有:** 3 つの版の間で会話履歴は共有されません。
